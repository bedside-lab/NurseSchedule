# 간호사 근무표 자동생성 프로그램 (PC 설치형)

제2중환자실 근무표 작성 규칙(3교대, 팀 균형, 나이트 인터벌 등)을 그대로 담은
윈도우용 프로그램입니다. GitHub Actions가 실제 윈도우 컴퓨터에서 빌드해주기
때문에, 별도 프로그램 설치 없이 완성된 `.exe` 파일 하나만 받아서 쓰면 됩니다.
(이전에 만드셨던 "업무알리미"와 같은 방식입니다.)

## 처음 한 번만: GitHub에 올리고 빌드받기

1. **GitHub 저장소 만들기**
   - https://github.com 에 로그인 후, 오른쪽 위 `+` → `New repository` 클릭
   - 이름은 원하는 대로 (예: `nurse-schedule-app`), Public/Private 아무거나 상관없음
   - `Create repository` 클릭 (README 추가 등 다른 옵션은 체크하지 않아도 됩니다)

2. **이 폴더를 그 저장소로 올리기**
   압축을 푼 이 폴더 안에서, 아래 명령을 터미널(명령 프롬프트/PowerShell)에
   차례로 입력합니다. `깃허브주소` 부분은 방금 만든 저장소 페이지에서
   `Quick setup`에 보이는 주소로 바꿔주세요 (예:
   `https://github.com/내아이디/nurse-schedule-app.git`).

   ```
   git init
   git add .
   git commit -m "첫 업로드"
   git branch -M main
   git remote add origin 깃허브주소
   git push -u origin main
   ```

   (컴퓨터에 git이 없다면 https://git-scm.com/downloads 에서 설치 후 진행)

3. **자동 빌드 확인하기**
   - push가 끝나면 GitHub 저장소 페이지 상단의 `Actions` 탭을 클릭
   - `Build Windows EXE`라는 작업이 자동으로 시작된 것을 볼 수 있습니다
     (보통 2~5분 정도 걸립니다)
   - 초록색 체크(완료)가 뜨면 그 작업을 클릭 → 아래쪽 `Artifacts` 항목에
     `NurseScheduleApp-windows`가 보입니다 → 클릭하면 zip으로 다운로드됩니다
   - 압축을 풀면 `NurseScheduleApp.exe`가 있습니다. 이 파일을 원하는 위치
     (바탕화면, USB 등)로 옮겨서 실행하면 됩니다. 별도 설치 과정은 필요 없습니다.

## 이후 규칙을 바꾸고 싶을 때

이 프로그램의 규칙 대부분(주간 최소 오프, 나이트 인터벌, 최대 연속근무 등)은
프로그램 화면의 "고급 설정"에서 직접 조정할 수 있어서, 대부분의 경우 코드를
건드리지 않아도 됩니다. 그래도 코드 자체를 바꿔야 하는 경우(예: 완전히 새로운
규칙 추가)는:

1. `scheduler/core.py` 파일을 수정
2. 저장 후 다시 `git add .` → `git commit -m "설명"` → `git push`
3. GitHub `Actions` 탭에서 새 빌드가 자동으로 시작되고, 완료되면 위와 같은
   방법으로 새 `.exe`를 받으면 됩니다.

매번 새로 다운로드해야 하며, 기존 `.exe`를 덮어쓰면 됩니다.

## 프로그램 사용법

1. `NurseScheduleApp.exe` 실행
2. **1. 파일 선택**: 신청 근무가 채워진 엑셀 파일 선택, 결과 저장 위치 지정
3. **2. 이번 달 설정**: 이전 달 기록 일수/이번 달 일수, 데이 전담 간호사 이름
   (쉼표로 구분), 근무조당 필요 인원(데이/이브닝/나이트)을 이번 달에 맞게 입력
4. 필요하면 **고급 설정**을 펼쳐서 세부 규칙 값 조정 (평소엔 기본값 그대로 둬도 됩니다)
   - "나이트 블록 간 최소 인터벌"이 두 개로 나뉘어 있습니다: **우선** 값으로
     먼저 시도하고, 그 값으로는 도저히 조건을 만족하는 근무표가 안 나올 때만
     자동으로 **안되면** 값으로 다시 계산합니다 (기본: 우선 6일 / 안되면 5일).
5. **근무표 생성** 버튼 클릭 → 계산에 몇 분 정도 걸릴 수 있습니다 (진행 로그에 표시됨)
6. 완료되면 지정한 위치에 완성된 엑셀 파일이 저장됩니다
   - 노란색 = 원래 신청했던 근무가 그대로 반영된 칸
   - 주황색 = 신청했지만 규칙과 충돌해서 관리자가 조정한 칸 (셀에 마우스를
     올리면 이유가 코멘트로 표시됨)
   - 맨 아래: 날짜별 D/E/N 인원수, 맨 오른쪽: 간호사별 D/E/N/O 합계

화면에서 입력한 값들은 자동으로 저장되어 다음 실행 때 그대로 불러옵니다
(파일 경로는 매달 새로 지정해야 합니다).

## 참고

- 이 프로그램은 100% 이 컴퓨터 안에서만 동작하며, 인터넷 연결이나 서버가
  필요 없습니다. 엑셀 파일도 외부로 전송되지 않습니다.
- 규칙 자체에 대한 자세한 설명은 `근무표_작성_조건.md`(별도 전달) 문서를 참고하세요.
